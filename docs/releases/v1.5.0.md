# ReachCommander v1.5.0

Generate English and Romanian subtitles from existing videos or folders using free local CPU models. Videos stay on the host, inference works offline after setup, and no OpenAI account or API key is needed.

## Changes

- Generate Subtitles from the toolbar or file context menu, with English selected by default and optional Romanian translation.
- Durable serial jobs, per-file progress, cancellation, restored history and skipping of verified completed outputs.
- Exact-basename SRT output, bilingual `.ro.srt` output, preservation of existing associated subtitles and transactional installation/recovery. Video contents and embedded subtitles are untouched.
- Readiness messages distinguish disabled generation, an unavailable worker and missing language models. Worker failures are detected promptly.
- Optional Ubuntu installer-managed CPU worker: explicit setup, retained models, existing source mappings, compatible application/worker image pins and lifecycle/rollback checks.
- Linux real-inference release verification, browser readiness acceptance tests, and worker/application manifest and anonymous-download checks before promotion.

## Upgrading an existing Ubuntu installation

1. Follow the [Ubuntu installation guide](https://github.com/dragosniamtu/reach-commander/blob/v1.5.0/docs/deployment/ubuntu.md) to obtain and verify this release's installer archive and checksums. Keep an independent backup of important application configuration and media.
2. Rerun the verified installer to refresh host tools while preserving the existing installation. An application-only update cannot install the new subtitle-management command.
3. Enable and prepare the optional worker:

   ```bash
   sudo reachcommander subtitles enable
   sudo reachcommander subtitles download-models
   sudo reachcommander subtitles status
   sudo reachcommander doctor
   ```

4. Select a short video in a writable source, choose **Generate Subtitles**, and verify the English/Romanian output and preserved backups before processing a large folder.

The default worker uses two CPU threads, Whisper small/INT8 and a 6 GB memory limit. Models total approximately 800 MB; images and dependencies require additional space. Normal updates preserve models and subtitle state. Source access remains read-only unless explicitly configured writable.

## Operational limits

- CPU processing time depends on the hardware, language and dialogue. Automatic results can need manual correction.
- One video is processed at a time; the default maximum duration is four hours.
- GPU support and automatic audio-track selection controls are outside this release.
- Before deliberately downgrading to an application without worker support, run `sudo reachcommander subtitles disable`. The older image is rejected while subtitles are enabled.
- macOS and custom deployments use the documented source-build overlay; the installed host-management integration targets Ubuntu.
- Preserve recovery journals/backups when a filesystem changes externally during installation. See the [subtitle runbook](https://github.com/dragosniamtu/reach-commander/blob/v1.5.0/docs/ai-subtitles.md).
