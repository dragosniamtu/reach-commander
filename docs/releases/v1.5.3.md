# ReachCommander v1.5.3

Upgrade Ubuntu host tools without re-entering the existing configuration. This resolves installations where the application shows Generate Subtitles but the older host command has no `subtitles` option.

## Fixes

- Add `install.sh --keep-config` to reuse validated network, port, runtime identity, CPU and source settings while updating the host management tools and updater service. The application follows the saved update channel.
- Retain administrator credentials, application data, subtitle enablement and downloaded models. Invalid or incomplete saved settings fail before replacing the deployment.
- Recreate the application container after refreshing the updater service, including during rollback, so its socket mount points to the current runtime directory.
- Reuse the existing installer backup, health checks and rollback transaction for this upgrade path.

## Upgrade and enable subtitles

Download and checksum-verify the v1.5.3 installer using the [Ubuntu installation guide](https://github.com/dragosniamtu/reach-commander/blob/v1.5.3/docs/deployment/ubuntu.md). Wait for active operations to finish, then run from the extracted installer directory:

```bash
sudo ./install.sh --keep-config
sudo reachcommander subtitles enable &&
sudo reachcommander subtitles download-models &&
sudo reachcommander subtitles status
```

The host upgrade briefly restarts the application. Model setup needs an internet connection; subtitle generation then runs locally on the CPU. Reload the app and recheck subtitle availability after setup succeeds.

Application-only updates cannot install the host management tools. Existing installations should use this verified installer upgrade once.
