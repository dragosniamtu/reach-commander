# ReachCommander v1.6.0

Repair existing subtitles without replacing their text, generate subtitles with corrected ending times, and access the application actions through one labeled Menu.

## Changes

- Replace the top toolbar's separate action icons with one Menu containing icons and labels. The Subtitles group contains Generate Subtitles, Repair subtitles and subtitle job history.
- Add repair for existing SRT subtitles in any language: decode supported legacy encodings, review ambiguous encoding choices, correct timing against the video's audio on the local CPU, and save UTF-8 while preserving the original text. Preview and manual timing adjustment remain available before saving.
- Preserve a byte-for-byte backup of each original subtitle before repair. Revalidate the file and source permissions before saving; the video is unchanged.
- Use Whisper word timestamps during generation so captions end after their spoken words instead of lingering across long silent gaps. Romanian translation retains the corrected timing.
- Add a default-on **Skip successfully processed videos** option. Turn it off to regenerate previously generated subtitles; existing subtitle files are backed up before replacement.
- Extend the host storage validation and worker readiness checks for the new repair queues. Repair uses the local CPU service and does not require Whisper or translation model downloads.

## Upgrade an existing Ubuntu installation

**Use the v1.6.0 installer once with `--keep-config`, even if subtitle generation is already enabled.** An application-only update does not refresh the host tools that recognize the new repair data.

Download and checksum-verify the installer using the [Ubuntu installation guide](https://github.com/dragosniamtu/reach-commander/blob/v1.6.0/docs/deployment/ubuntu.md). After active operations finish, run these commands from the extracted installer directory:

```bash
sudo ./install.sh --keep-config
sudo reachcommander doctor
sudo reachcommander subtitles status
```

The installer keeps saved network settings, sources, permissions, administrator credentials, subtitle enablement and downloaded models. The application briefly restarts. If the subtitle service was not previously enabled, run `sudo reachcommander subtitles enable` to use automatic repair.

Reload ReachCommander after upgrading. Previously generated files retain their old timestamps until regenerated: select the video, open **Menu → Subtitles → Generate Subtitles**, select the desired languages, and uncheck **Skip successfully processed videos**. To retain an existing subtitle's text, choose **Repair subtitles** instead; repair can correct an overall timing offset and drift, but regeneration is needed to recalculate generated caption endings.
