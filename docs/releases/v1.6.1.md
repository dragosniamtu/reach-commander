# ReachCommander v1.6.1

Generated subtitles now remain visible for up to one extra second after their original ending time, giving viewers more time to read.

- End the caption at the next caption's start if it begins within that extra second, so captions never overlap.
- Keep all caption start times unchanged, including captions split into shorter display blocks.
- Apply identical ending times to generated English and Romanian subtitles. Longer pauses still clear the screen.

## Update

For installations whose host tools were already refreshed with the v1.6.0 installer:

```bash
sudo reachcommander update stable
sudo reachcommander subtitles status
```

If upgrading from older host tools, first follow the [verified installer upgrade with `--keep-config`](https://github.com/dragosniamtu/reach-commander/blob/v1.6.1/docs/deployment/ubuntu.md#upgrade-host-tools-without-reconfiguration) to retain the saved configuration and update subtitle repair support.

Previously generated subtitles keep their current timestamps. To apply the new reading buffer, select the video, open **Menu → Subtitles → Generate Subtitles**, select the desired languages and uncheck **Skip successfully processed videos**. Existing subtitles are backed up before replacement. Repairing an existing subtitle does not apply this generation-only buffer.
