# ReachCommander v1.7.0

Generate subtitles for multiple selected videos in one job. Select files with Ctrl-click or Shift-click, then open **Menu → Subtitles → Generate Subtitles** to review the list and choose languages once.

- Process the selected videos one at a time, in the displayed order, using the existing local CPU service.
- Show pending, running, completed, skipped and failed results for each file. Jobs continue when the dialog or browser closes, and progress is restored after a page reload.
- Continue with the remaining videos after an individual failure; Cancel stops the active video and cancels the remaining work.
- Keep the existing subtitle backups, English/Romanian choices, skip-successful option and one-second reading buffer.
- Check the full selection before queueing, and detect videos that change or become read-only while waiting. Single-video and recursive folder generation remain available.

## Update

For installations whose host tools were refreshed with the v1.6.0 or v1.6.1 installer, no reconfiguration or model download is required:

```bash
sudo reachcommander update stable
sudo reachcommander subtitles status
sudo reachcommander doctor
```

Refresh the browser after the update. Batch generation is also available from the selected files' right-click menu.

Older host installations must first follow the [verified installer upgrade with `--keep-config`](https://github.com/dragosniamtu/reach-commander/blob/v1.7.0/docs/deployment/ubuntu.md#upgrade-host-tools-without-reconfiguration). This retains saved settings and models while adding support for the subtitle repair queues introduced in v1.6.0.
